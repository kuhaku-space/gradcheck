# 修了要件と判定仕様

対象: 大阪大学大学院情報科学研究科 博士前期課程 **コンピュータサイエンス専攻**

根拠: [大阪大学大学院情報科学研究科規程](https://www.osaka-u.ac.jp/kitei/reiki_honbun/u035RG00000399.html)
別表1「情報科学研究科専攻別授業科目表」コンピュータサイエンス専攻（前期課程）
（2026-07-07 参照）

> **免責**: 本アプリの判定は参考情報である。規程の改定・入学年度による経過措置・
> 専攻が個別に認める科目（他研究科提供科目等）を完全には反映できないため、
> 正式な修了判定は必ず教務係に確認すること。

## 規程上の修了要件

> 修了要件：本専攻が指定する科目から専攻基礎科目22単位以上を含め、
> 30単位以上を修得し、別に定める研究指導を受けなければならない。
> なお、当該30単位には、次に示す修得単位数を含めなければならない。

| 教育課程区分 | 修得単位数 |
|---|---|
| 専門教育科目 | 22単位以上（注） |
| 高度国際性涵養教育科目 | 1単位以上（注） |
| 高度教養教育科目 | 2単位以上 |

必修・選択必修（別表1 の科目表より）:

- **必修**: コンピュータサイエンス研究Ⅰa（2）、コンピュータサイエンス研究Ⅰb（2）
- **選択必修**: 次の 1、2 のいずれかから 4 単位
  1. コンピュータサイエンス演習Ⅰ（2）及びコンピュータサイエンス演習Ⅱ（2）
  2. インタラクティブ創成工学基礎演習A（4）

（注）**二重区分科目の充当規則**: 専門教育科目と高度国際性涵養教育科目の両方に
○が付いた科目（コンピュータサイエンス基礎論、英語プレゼンテーション、
海外インターンシップM、国際融合科学論）の単位を修得した場合は、
**高度国際性涵養教育科目に優先して充当**する。ただし、高度国際性涵養教育科目の
必要修得単位（1単位）を既に充足している場合は、専門教育科目の単位に充当する。

このほか「別に定める研究指導」が必要だが、CSV からは判定できない（後述）。

## アプリの判定仕様

### 入力

KOAN の成績 CSV（詳細は [csv-format.md](csv-format.md)）。
「合否」列が `合` の行のみを修得単位として数える（`否` は不合格）。

### 入学年度と適用ルールセット

修了要件は「現在の規程」ではなく「入学時点の規程＋経過措置」で決まる
（規程の附則に「改正時点で在学中の者はなお従前の例による」旨の経過措置がある）。

- 学籍番号の3〜4文字目を入学年度の下2桁として推定する
  （例: `33C24019` → 2024年度入学。`src/lib/studentId.ts`）
- 入学年度に応じたルールセット（`src/lib/rules.ts` の `RULE_SETS`）を選んで判定する
- 推定できない場合は最新ルールで判定し、警告を表示する
- 定義済みルールより前の入学年度の場合は最古の定義で判定し、
  経過措置により要件が異なる可能性がある旨を警告する

現在定義されているルールセットは「2024年度以降入学（現行規程に基づく）」のみ。
規程改定で単位数要件等が変わった場合は `RULE_SETS` に新しい入学年度からの
定義を追加する（既存の定義は変更しない）。

### 科目の区分判定

CSV の「科目詳細区分」「科目小区分」列から次のように分類する。

| CSV 上の区分 | アプリ内カテゴリ |
|---|---|
| 専門教育系科目 ＋ 専攻基礎科目（必修） | 専攻基礎（必修） |
| 専門教育系科目 ＋ 専攻基礎科目（選択必修1） | 専攻基礎（選択必修） |
| 専門教育系科目 ＋ 専攻基礎科目（選択） | 専攻基礎（選択） |
| 専門教育系科目 ＋ 専攻境界科目 | 専攻境界 |
| 教養教育系科目（高度教養教育科目） | 高度教養教育科目 |
| 国際性涵養教育系科目（高度国際性涵養教育科目・専門教育科目） | 二重区分（充当規則を適用） |
| 国際性涵養教育系科目（上記以外） | 高度国際性涵養教育科目 |

二重区分科目は規程の（注）に従い、高度国際性涵養教育科目の 1 単位が
未充足の間はそちらへ、充足済みなら専門教育科目（専攻基礎/専攻境界は
科目小区分に従う）へ科目単位で充当する。

### 判定項目

| # | 要件 | 判定方法 |
|---|---|---|
| 1 | 必修科目の修得 | 研究Ⅰa・Ⅰb がともに合格 |
| 2 | 選択必修 4 単位 | （演習Ⅰ かつ 演習Ⅱ）または 基礎演習A が合格 |
| 3 | 専攻基礎科目 22 単位以上 | 専攻基礎に充当された合格単位の合計 ≥ 22 |
| 4 | 専門教育科目 22 単位以上 | 専攻基礎＋専攻境界に充当された合格単位 ≥ 22 |
| 5 | 高度国際性涵養教育科目 1 単位以上 | 充当後の合計 ≥ 1 |
| 6 | 高度教養教育科目 2 単位以上 | 合格単位合計 ≥ 2 |
| 7 | 総修得単位 30 単位以上 | 全カテゴリの合格単位合計 ≥ 30 |
| 8 | 研究指導 | **CSV から判定不能** — 要確認事項として表示 |

科目名の照合は、ローマ数字の表記ゆれ（`Ⅰ`/`I`/`Ｉ`、`Ⅱ`/`II` など）と
前後空白を正規化した上で行う。

### 出力

- 総合判定（要確認事項を除く全項目の充足/不足）
- 要件ごとの充足状況・現在単位数・不足単位数
- 読み込んだ科目の一覧（区分・単位・評語・合否・充当先）
